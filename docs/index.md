# Sandwich Steam
{: .no_toc }

Steam for Unreal Engine 5, made friendly. Achievements, stats, leaderboards, lobbies, voice chat, Steam Input, cloud saves and more, from **Blueprints** or **C++**.

## What you need to know first

- **It is a source plugin.** Unreal compiles it on your PC the first time you open the project. You do not have to write C++, but a compiler must be installed. The [installation guide](installation.html) holds your hand through it.
- **Test in Standalone, not Play In Editor.** Steam only runs in a real game process. Use **Play > Standalone Game**.
- **You do not need to buy anything to start.** Valve's public test app *Spacewar* (App ID `480`) works for every Steam account.

## Project status

Windows is tested. macOS and Linux are experimental. Some multiplayer and controller features are still waiting for real-world testing. The [README](https://github.com/SandwichCakeStudios/SandwichSteam#project-status) has the full table.
